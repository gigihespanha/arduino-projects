# Projeto 22 – Sistema de Acesso com Teclado Matricial

## Descrição
Neste projeto é desenvolvido um sistema de acesso por senha utilizando
teclado matricial e display LCD 16x2 com comunicação I2C. O sistema valida
a senha digitada e libera ou nega o acesso através de um LED.

## Componentes
- Arduino UNO
- Teclado Matricial 3x4 ou 4x4
- Display LCD 16x2 com módulo I2C
- LED
- Resistor de 220Ω
- Protoboard
- Jumpers

## Funcionalidades
- Leitura de teclas do teclado matricial
- Exibição de mensagens no LCD
- Validação de senha
- Indicação visual de acesso permitido ou negado

## Comunicação
- LCD via I2C
- Teclado via pinos digitais
