# Projeto 16 – Controlando dois servos com biblioteca

## Descrição
Neste projeto controlamos 2 servos simultaneamente usando a biblioteca Servo.h.
Os dois servos giram juntos até 90° e depois até 180°.

## Componentes
- Arduino UNO
- 2 Servos
- Protoboard
- Jumpers

## Ligações (padrão)
- Servo 1 (sinal) → pino 2
- Servo 2 (sinal) → pino 3
- VCC servos → 5V
- GND servos → GND
