# Arduino Projects (Portfolio)

This repository contains Arduino projects developed during the **Mestres do Arduino** course.
Projects are organized in individual folders, each with:
- `README.md` (project description)
- `code/` (Arduino `.ino` file)

## Highlights (recommended)
- Projeto 10 — LM35 + AREF (more accurate analog readings)
- Projeto 15 — Servo control with potentiometer (manual pulse control)
- Projeto 16 — Two servos using Servo.h
- Projeto 17 — LCD 16x2 via I2C
- Projeto 18 — Two I2C LCDs (different addresses)
- Projeto 22 — Access system with keypad + LCD (password validation)

## Structure
Each project follows:

Projeto_xx_Name/
README.md
code/
Projeto_xx_Name.ino
