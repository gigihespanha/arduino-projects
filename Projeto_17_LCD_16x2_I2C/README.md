# Projeto 17 – Utilizando Display LCD 16x2 I2C

## Descrição
Neste projeto utilizamos um display LCD 16x2 com módulo I2C para facilitar
as conexões e exibir informações no display.

## Componentes
- Arduino UNO
- Display LCD 16x2 com módulo I2C
- Protoboard
- Jumpers

## Ligações (I2C)
- VCC → 5V
- GND → GND
- SDA → A4
- SCL → A5
