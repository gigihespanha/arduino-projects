# Projeto 18 – Dois Displays LCD 16x2 I2C ao mesmo tempo

## Descrição
Neste projeto controlamos dois displays LCD 16x2 utilizando comunicação I2C,
cada um com um endereço diferente, exibindo informações simultaneamente.

## Componentes
- Arduino UNO
- 2 Displays LCD 16x2 com módulo I2C
- Protoboard
- Jumpers

## Ligações (I2C)
- VCC → 5V
- GND → GND
- SDA → A4
- SCL → A5

## Endereços I2C
- LCD1 → 0x27
- LCD2 → 0x26
